# Thermal-Monitoring-Additive-Manufacturing
Thermal-camera-based early defect detection for large-format 3D printing.


## Goal

Large-format (big-area) 3D printing can fail in costly ways — collapsed
layers, poor bonding between layers, and residual stress caused by uneven
cooling between neighboring layers. This project looks at whether thermal
camera data collected during printing can give an early signal of these
issues, ideally while a print is still running rather than only after it's
finished.

## What we've done

We've built and evaluated a prototype that processes thermal imaging data
from real large-format prints and flags regions that deviate from normal
thermal behavior.

## Dataset

This work is built around publicly available thermal-imaging data from
large-format additive manufacturing prints.

- Dataset: [https://doi.ccs.ornl.gov/dataset/98573c97-cfd5-5d4e-b62f-cad6b927736b]
